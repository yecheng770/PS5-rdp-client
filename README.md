# PSrdp — 把 PS5 变成 Windows 远程桌面大屏

PSrdp 让你的 PS5 变身 Windows 电脑的大屏终端：连上局域网里那台 Windows，
游戏机的画面就是电脑的桌面，手柄当鼠标、软键盘打字、声音从 PS5 音响出来。
**系统级原生应用**——不是浏览器套壳、不是模拟器、不需要云端中转。

## 核心卖点

**🖥️ 任意自定义分辨率**

不止一款预设——分辨率随便填。常用的 **1080P、2K、4K 全部经过真机逐档
调试验证**，非标准分辨率（如 2560×1440、3440×1440 带鱼屏）也能直接连。
1080P 全屏重画实测 **59.6fps**，画面直写 PS5 视频输出，延迟低到
日常办公感觉不到。

**🎮 手柄/鼠标/键盘 三套输入并存**

- **手柄**：左摇杆=指针，L2/R2=鼠标左右键；触摸板面+按键自定义
- **鼠标**：PS5 上接了 USB 鼠标应用即尝试启用（依赖系统授予，一部分机型/固件下可用）
- **键盘**：物理键盘接上可打字；没有键盘用内置软键盘（中英日法俄五语布局）
- 三种输入同时在线，随你切换

**🔊 音频原生回传**

Windows 的一切声音——系统提示、音乐、会议——实时走 48kHz 立体声从
PS5 播放，不用外接音响。视频节的音画同步已真机调通。

**⚙️ 其他**

- 浏览器式配置面板：存最近 5 组连接历史、分辨率/缩放快捷切换
- 远程设备重定向：把电脑磁盘映射给 PS 应用使用（RDPDR）
- 五国语言界面：简中 / English / 日本語 / Français / Русский
- 待机装饰动画（转球+手柄），可关
- 右下角签名显示作者与仓库地址

## 适用与不适用

**最适合**：办公、写代码、跑终端、看文档、浏览静态网页——一句话，**一切
不动鼠标拖视频进度条的场景**。

**不适合**：看视频、玩游戏。本应用走**位图传输**（每帧整屏重画 59.6fps），
对桌面操作极稳，但动态视频会卡顿——这是位图方案的物理天花板，不是
bug。流畅视频/游戏需要后续的图形线版本（GFX），单独发布。

## 安装

**前置**：一台可跑自制应用的 PS5 + 局域网里一台开了远程桌面的
Windows（专业版：设置→系统→远程桌面）。

1. 下载 [Release](../../releases) 的 `PPSA90042-*.ffpfs`，用你的 loader
   （ShadowMount+、etaHEN 等）导入，主页出现 **PSrdp**
2. 启动 PSrdp，**在应用内**（手柄+软键盘即可，全流程不需要浏览器）
   填 Windows 的 IP、账号、密码
3. 连接成功，PS5 画面立刻变成你的 Windows 桌面

首次启动不预置任何 IP/账号，全靠你自己填。

## 从源码编译

完整源码在 `源码/`，一台 Linux（Ubuntu 22.04+）就够：

```bash
cd 源码
cp .env.example .env      # PS5_HOST 填你自己的
make app                  # 编译+签名+打包，产物在 dist/
```

首次构建自动下载 ps5-payload-sdk v0.42 并做 SHA256 校验，无需手动配置。

## 工作原理

PS5 没有官方 RDP 客户端，也没有通用桌面 API。PSrdp 是一个自制的原生应用：

1. 以应用形式装进 PS5 主页（titleId `PPSA90042`），启动后画出自己的
   配置界面
2. 用户在应用内填好 Windows 侧 IP/账号，应用用 FreeRDP 3.x 发起 RDP 连接
3. Windows 桌面被编码成位图帧，经网线传到 PS5，直接写入
   VideoOut 显存（不经游戏引擎，零依赖）
4. 手柄/键盘/鼠标输入在 PS5 侧抓取，反向传给 Windows
