# PSrdp — 在 PS5 上跑的 Windows 远程桌面

把你的 PS5 变成 Windows 电脑的第二块屏幕：拿手柄躺在沙发上，直接看到并操作
你电脑上的桌面、窗口、浏览器、终端。局域网内直接连接，不依赖任何云服务。

## 能干什么

| 功能 | 说明 |
|---|---|
| 全屏桌面串流 | 1920×1080 @ ~59.6fps，画面直写 PS5 视频输出 |
| 音频回传 | Windows 的声音实时传到 PS5（48kHz 立体声） |
| 手柄操作 | 左摇杆=鼠标指针，L2/R2=左键/右键 |
| 键盘输入 | 支持文字输入，中英文界面切换 |
| Web 配置页 | 浏览器打开改 IP/账号/端口，保存最近 5 组连接 |
| 设备重定向 | 远程设备磁盘/串口映射到会话 |
| 多语言界面 | 简中 / English / 日本語 / Français / Русский |
| 装饰动画 | 待机页有转动的地球与手柄装饰（可关） |

**已知限制**：应用采用位图传输方案，**看视频/看网页动态内容会卡顿**。
文档、办公、终端这类低帧场景完全没问题。视频支持由后续图形线版本解决。

## 安装到 PS5

**前置条件：**

- 一台已破解的 PS5（可运行自制应用）
- 局域网内一台已开启"远程桌面"的 Windows 电脑
  （Windows 10/11 专业版：设置→系统→远程桌面→开）

**三步走：**

1. 下载本仓库的 `dist/PPSA90210*.ffpfs`（或自己源码编译生成的），通过
   你在用的 loader（ShadowMount+、etaHEN 等）装到 PS5
2. 主页会出现 **PSrdp** 应用。启动后用电脑浏览器访问
   `http://<PS5的IP>:8081` 进入配置页，填 Windows 的 IP 和账号
3. 回到应用，整个 Windows 桌面已经在 PS5 上了

首次启动不预置任何 IP/账号，必须自己填，这是刻意的安全设计。

## 从源码编译

完整源码在 `源码/` 目录，可在 Linux 机器（Ubuntu 22.04+）上编译：

```bash
cd 源码
cp .env.example .env     # 改 PS5_HOST 为你的 PS5 内网 IP
make app                 # 编译+签名+打包，产物在 dist/
```

首次构建会自动下载官方 ps5-payload-sdk 并校验哈希，无需手动配置。
构建产物可以直接上传 PS5 用。

## 工作原理

PS5 没有官方 RDP 客户端。PSrdp 是一个自制应用：

1. 以应用形式装进 PS5 主页（titleId `PPSA90210`），启动后先起一个
   小型 HTTP 服务做配置页和状态面板
2. 用户在配置页填好 Windows 侧信息，应用用 FreeRDP 3.x 发起 RDP 连接
3. Windows 桌面被编码成位图帧，经网线传到 PS5，直接写入 VideoOut 显示
4. 手柄/键盘/鼠标输入在 PS5 侧被反向传给 Windows

没有虚拟机、没有模拟器、没有游戏引擎，就是原生应用。
